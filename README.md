# VYRO portfolio website

This is a static website. The entry page is `index.html`; no build step or package installation is needed.

## Deploy to Netlify

1. Sign in to Netlify and create a new site by deploying a project folder.
2. Upload this folder (or connect its Git repository).
3. Netlify reads `netlify.toml` and publishes the site from the project root.

The site uses relative file links, so it can also be hosted by other static website providers. Keep the HTML, CSS, and JavaScript files together when uploading.
